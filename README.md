# 📊 FinSight AI

> **재무제표 이상징후 탐지 + 전표 분류를 한 곳에서 처리**

FinSight AI는 재무·회계 담당자가 반복적으로 하는  
**증감 비교, 이상 계정 확인, 원본 대조, 전표 분류** 작업을 더 빠르게 처리하기 위해 만든 프로젝트입니다.

---

## 왜 쓰나요?

재무제표를 검토할 때는 숫자를 보는 것보다 다음 작업에 시간이 많이 듭니다.

- 전기와 당기 금액 비교
- 큰 변동이 발생한 계정 찾기
- 관련 계정과 원본 데이터 다시 확인
- 잘못된 값을 수정하고 다시 분석
- 반복되는 전표 계정과목 분류

FinSight AI는 **사람이 직접 확인해야 할 항목을 먼저 좁혀주는 것**을 목표로 합니다.

---

## 핵심 기능

### 🔎 재무제표 이상징후 탐지
전기 대비 증감, 재무적 중요성, 관련 계정 신호, 다기간 추세 이탈을 분석해 **검토 우선순위**를 정리합니다.

### ✅ 데이터 검증·수정
Excel / CSV / PDF / DOCX 데이터를 불러와 매핑을 확인하고, 프로그램 안에서 금액과 계정 정보를 수정한 뒤 다시 분석할 수 있습니다.

### 🧾 원본 추적
분석에 사용된 값의 파일, 시트, 셀 또는 페이지 정보를 확인해 원본까지 빠르게 내려갈 수 있습니다.

### 💳 전표 분류
Excel / CSV 전표를 불러와 계정과목 추천, 승인·반려, 중복 의심 거래 확인을 지원합니다.

### 💰 금액 단위 처리
내부 계산은 **원(KRW)** 기준으로 통일하고, 화면에서는 `1,000,000`처럼 천 단위 구분을 적용합니다.  
필요에 따라 원 / 천원 / 백만원 / 억원 단위로 보기 쉽게 확인할 수 있습니다.

## 분석 원칙

> **AI가 회계 결론을 대신 내리는 것이 아니라, 사람이 확인해야 할 부분을 빠르게 찾도록 돕는 도구**입니다.

계산과 검증은 Python 엔진에서 처리하며, 원인이 확인되지 않은 이상징후를 임의로 단정하지 않습니다.  
검토 우선순위 점수는 감사 위험 확률이 아니며 최종 회계 판단은 사용자에게 있습니다.
